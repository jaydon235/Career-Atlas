# Career Atlas

Career Atlas is a career exploration tool designed to help users discover potential career paths based on their college degree, certifications, skills, and interests.

The goal of this project is to create a simple but powerful application that connects education and training to real-world career opportunities using structured data and (eventually) public labor market APIs.

---

## 🎯 Project Goals

- Allow users to input a current or intended degree
- Show related career options
- Display salary ranges, job outlook, and education requirements
- Expand to include certifications and skills (A+, AZ-900, etc.)
- Eventually integrate real-world data from sources like:
  - U.S. Bureau of Labor Statistics (BLS)
  - O*NET occupational database
